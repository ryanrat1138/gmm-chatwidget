Chat embed setup

Adds the CloseBot AI chat to a page with one tag. On the thank-you page it fills in the visitor's name, email and phone from the form they just sent, so the chat starts on their existing HighLevel contact.

1Get the code

In CloseBot, open your HighLevel source and go to Setup. Paste the whole script tag here; the ID is the part after source=.


    
  


  

    
2Paste it on two pages

    
    
      
  • The page with the form and the thank-you page. Same code on both.
    • 
      
  • On the thank-you page, put it where the chat should appear (for the in-page layout) and above any analytics or tracking code if the builder allows.
    • 
      
  • HighLevel: use a Custom JS/HTML element. WordPress: a Custom HTML block.
    • 
      
  • If CloseBot's own script tag is already on the site, you can leave it; the embed won't load CloseBot twice. Put the embed above it so CloseBot never sees contact details in the address bar.
    • 
    

  


  

    
3Turn on CloseBot's contact form

    
    
      
  • In the chat widget settings, open Form, turn it on, include Email and Phone, and set it to show immediately.
    • 
      
  • Make sure the widget is targeted to the thank-you page URL and the site's domain is on the source's allowed domains.
    • 
    

    
The embed fills and sends that form for the visitor. If it can't find their details, they fill it in themselves as usual.

  


  

    
4Typeform only: send the answers to the thank-you page

    
In Typeform, open Endings, turn on Redirect to URL, and enter the thank-you page address followed by the answers:

    
https://your-site.com/thank-you?email=@Email&phone=@Phone&first_name=@First name

    
Type the part before each @ yourself, then type @ and pick the matching question from the list. The embed removes these details from the address bar as soon as the page opens.
