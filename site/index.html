Chat embed setup

Adds the CloseBot AI chat to a page with one tag. On the thank-you page it fills in the visitor's name, email and phone from the form they just sent, so the chat starts on their existing HighLevel contact.

1Thank-you page: the chat

In CloseBot, open your HighLevel source and go to Setup. Paste the whole script tag here; the ID is the part after source=.

How the chat shows

Shown as the bot's first message when the chat would otherwise open empty, because the visitor's details were sent for them. {first_name} becomes their first name, or "there" if it isn't known. Leave it empty for none. If you set a Welcome Message in CloseBot, that shows instead.

Names of details passed in the thank-you page address or asked on your own form, separated by commas. Each is saved to the HighLevel contact field with the same key, which the AI can read. The field must exist in HighLevel and be on the service's allowed list.


    
    
    
      
  • Paste it where the chat should appear. HighLevel: a Custom JS/HTML element. WordPress: a Custom HTML block.
    • 
      
  • Keep it above any analytics or tracking code if the builder allows, so they never see the visitor's details in the address bar.
    • 
      
  • If CloseBot's own script tag is already on the site, you can leave it; the chat won't load twice.

2Form page: no chat, just remembers the details

    
Only needed when the form is on your own website, including a HighLevel form embedded there. Skip it for Typeform and for HighLevel funnel forms. No chat shows on the form page.

    

    
  


  

    
3In CloseBot

    
    
      
  • In the chat widget settings, open Form, turn it on, include Email and Phone, and set it to show immediately.
    • 
      
  • Target the widget to the thank-you page URL only, so CloseBot doesn't show it on the form page either, and put the site's domain on the source's allowed domains.
    • 
    

    
The embed fills and sends that form for the visitor. If it can't find their details, they fill it in themselves as usual.

  


  

    
4Typeform only: send the answers to the thank-you page

    
In Typeform, open Endings, turn on Redirect to URL, and enter the thank-you page address followed by the answers:

    

    
Type the part before each @ yourself, then type @ and pick the matching question from the list. The embed removes these details from the address bar as soon as the page opens.
