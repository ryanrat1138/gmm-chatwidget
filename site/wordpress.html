JARchat for WordPress Setup

The JARchat WordPress plugin

Set up JARchat right inside WordPress and save it with one click, then add the chat to any page with a shortcode. No code to copy, no script tags in the page editor, and nothing for script optimizers to break.

Download the plugin Version 1.2.0 · WordPress 5.7 or later · PHP 7.2 or later

Install and activate

  1. Download the plugin with the button above. Keep it as a .zip file; don't unzip it.
  2. In WordPress, go to Plugins › Add New Plugin and click Upload Plugin at the top.
  3. Choose jarchat-wordpress.zip, click Install Now, then Activate Plugin.
  4. Go to Settings › JARchat. The JARchat setup opens right there; work through its steps.
  5. At the last step, click Save to WordPress.
  6. Edit the thank-you page, add a Shortcode block where the chat (or its card) should appear, and type [jarchat].

If your form is on this same WordPress site, also put [jarchat_form] on the form page; Save to WordPress saves its code too. Typeform and HighLevel funnel forms don't need it. To paste code from the setup page yourself instead, open Saved code under Settings › JARchat.

Shortcodes

ShortcodeWhat it does
[jarchat]Adds the chat to the thank-you page with your saved settings.
[jarchat_form]Goes on the form page. It shows no chat; it remembers what the visitor submits.

Changing one page

Any setting from the code can be changed for a single page by naming it in the shortcode without the data- part, for example [jarchat layout="bubble"], [jarchat cta="off"] or [jarchat greeting="Hi {first_name}!"].

Updating

The chat itself loads from JARchat's server, so most improvements reach your site without touching the plugin. When a new plugin version is listed below:

  1. Download the plugin again from this page.
  2. Go to Plugins › Add New Plugin › Upload Plugin and upload the new file.
  3. WordPress says the plugin is already installed. Click Replace current with uploaded.

Your saved code and shortcodes stay as they are. To change the chat later, go back to Settings › JARchat, go through the setup again and click Save to WordPress.
