Chat embed: step-by-step guide

How to get your CloseBot source ID, and how to send Typeform answers to the thank-you page so the chat knows who the visitor is and what they told you.

Find your CloseBot source ID

Each CloseBot source has its own script. The source ID is the code at the end of it.

  1. Sign in at app.closebot.com.
  2. Open the source connected to your HighLevel account, then click Setup.
  3. Find the pixel script on the Setup page and copy all of it. It looks like this: 
    <script src="https://api.closebot.com/scripts/cb.js?source=4ts0AHLEWQsK5N84"></script>
    The highlighted part after source= is the source ID.
  4. Paste the whole script into the CloseBot source ID box on the setup page. It picks out the ID for you, or you can paste just the ID.
  5. While you're on CloseBot's Setup page, add your website under Allowed domains, for example greatmountainmarketing.com, plus www.greatmountainmarketing.com if the site uses www (or *.greatmountainmarketing.com for every subdomain). CloseBot ignores pages on domains that aren't listed.
  6. Under Chat Widgets, open your widget (or click New Widget), turn on its Form with Email and Phone, set it to show immediately, and target it to your thank-you page only.

You don't need to paste CloseBot's own script on the thank-you page as well. The embed loads it for you. If it's already in your site header, that's fine too; it won't load twice.
CloseBot's help: Setup, Creating widgets.

Send Typeform answers to the thank-you page

When someone finishes the Typeform, it sends them to your thank-you page with their answers in the address. The embed reads them, removes them from the address bar, and hands them to the chat.

Redirecting to a URL needs a Typeform Plus plan or higher.

  1. On the setup page, fill in Form answers for the AI first if you want any (see below). Section 4 of the setup page then shows the full redirect link to build.
  2. In Typeform, open your form. In the Content panel, click + next to Endings and choose Redirect to URL. Pick URL as the destination.
  3. Type your thank-you page address followed by ?, then add each detail as name=answer, joined with &. For each answer, type the name and = yourself, then type @ and pick the matching question from the list: 
    https://greatmountainmarketing.com/thank-you/?email=@Email&phone=@Phone&first_name=@First name&business_info=@What does your business do?
    Typeform shows each picked question as a tag in the address. Don't type the question text yourself.
  4. Make sure the address starts with https://. Typeform won't redirect otherwise.
  5. Click Publish (or Publish edits) so the change goes live.

What to put in "Form answers for the AI"

Short names for the extra answers you want the AI to know about, separated by commas. Leave it empty if the AI only needs the contact details.

  1. Pick the Typeform questions the AI should know about, such as what their business does, team size or budget.
  2. Give each one a short name using lowercase letters, numbers and underscores, no spaces: business_info, team_size, budget.
  3. Type those names into the box, separated by commas: 
    business_info, team_size, budget
  4. Use exactly the same names in the Typeform redirect link, each followed by = and the question picked with @: 
    &business_info=@What does your business do?&team_size=@How big is your team?&budget=@Monthly budget
    The setup page's section 4 builds this part of the link for you once the names are in the box.
  5. Copy the thank-you page code again from the setup page, since the names are now part of it, and replace the old code on the page.

The answers ride along with the visitor's first chat message, as a note like [Form answers, for reference: Business info: HVAC; Team size: 6-20]. The AI reads it; the visitor never sees it. It does show in the HighLevel conversation, as part of their message. Names are turned into labels for the AI, so business_info reads "Business info".

Fill it in from your Typeform

Optional. The setup page can read your form's questions, pick out the email, phone and name questions, and build the answer names and redirect link for you. Reading changes nothing on the form; it can then also write the redirect into the form if you ask it to.

  1. In Typeform, click your profile picture in the top right and go to Account › Your settings › Personal tokens.
  2. Click Generate a new token and give it a name, such as Chat embed.
  3. Under Scopes, choose Custom scopes and tick Forms: Read. Also tick Forms: Write if you want the setup page to write the redirect into the form for you.
  4. Click Generate token and copy it. Typeform shows it only once.
  5. On the setup page, open Fill this in from your Typeform in section 4. Paste your form's share link (for example https://form.typeform.com/to/AbC123) and the token, then click Read my form.
  6. Check the Use as column: email, phone and name questions are set for you. Choose For the AI on each other answer the AI should know, and adjust its short name if you like.
  7. Fill in the Thank-you page address, then copy the thank-you page code from section 1.
  8. Either build the redirect shown in section 4 in Typeform yourself, picking each question named after an @, or let the setup page write it:
    • The form needs exactly one Redirect to URL ending. If it has none, add one in Typeform with any address and publish.
    • Tick the confirmation and click Write the redirect into my form. The page saves the form, reads it back and tells you if anything other than the redirect changed.
    • Open the ending in Typeform: the address should show each answer as a question tag, like the ones the @ picker adds.

Try the write on a duplicate first. In your Typeform workspace, open the form's … menu and choose Duplicate, then use the duplicate's link. Typeform's API saves the whole form at once, and it works from the published version, so publish any edits before writing or they can be lost.
The token is sent to Typeform for each step and isn't saved anywhere. You can delete it in Typeform afterwards.

Test it

  1. Open your Typeform in a private (incognito) window, so CloseBot doesn't already know you, and submit it with a real-looking email.
  2. On the thank-you page, the address bar should drop the answers within a moment, and the card should say "You're all set," with your first name.
  3. Send a message in the chat. The AI's reply should already know your answers.
  4. In HighLevel, the conversation should be on the contact the form created, with no duplicate contact.

If the card says "You're all set!" with no name, the redirect link is missing first_name or its @ question. If the chat asks for name and email, the link is missing email and phone.
